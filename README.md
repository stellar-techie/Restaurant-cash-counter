🍔 Restaurant Cash Counter Web Game

A beginner-friendly web-based restaurant POS simulation built using HTML, CSS, and vanilla JavaScript.
The application allows users to create customizable food orders, calculates prices dynamically, and generates receipt-style bills.

🚀 Features

Select food items (Burger, Pizza, Sandwich)

Customize orders with bread types, patties, cooking styles, and toppings

Real-time price calculation based on selected options

Auto-incrementing order numbers for each customer

Receipt-style bill generation

Clean, data-driven architecture (no hardcoded prices)

🛠 Tech Stack

HTML – Structure

CSS – Layout and styling

JavaScript (Vanilla) – Logic, state management, and DOM manipulation

No frameworks or external libraries are used.

🧠 How It Works

All menu items and prices are stored in JavaScript objects

A single order state object manages the current customer’s order

Total price is calculated dynamically from the order state

UI updates automatically as selections change

Generating a bill resets the order for the next customer
